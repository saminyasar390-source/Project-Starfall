# Project Starfall

Roguelike survival bullet-haven for Android (inspired by HoloCure / Vampire Survivors).

## Current state
- Main menu screen with the artwork (Play works, other buttons are "Coming soon")
- Game screen: scrolling forest map, Rin with a floating joystick, auto-fire, slime + wolf enemies,
  XP gems, level counter, HP/XP bars, game over screen

## Next steps
Level-up upgrade cards (RecyclerView), character select, map select, Services (music), Firebase leaderboard.
